### 2.2 【B1 · P2 · 已修】公告详情页与列表页显示同一条公告**相差 8 小时**

| 项 | 内容 |
|---|---|
| **现象** | 同一条公告，**列表页**与**详情页**显示的时间**相差 8 小时**（东八区） |
| **证据** | ① 服务端实测下发 UTC 带 Z：`createdAt = 2026-10-04T08:15:51.486Z`；② 列表页 `announcements_page.dart` 的 `timeText` **有** `.toLocal()`（L274-279）；③ 详情页 `_formatTime` **没有** → 两页必然错开一个时区 |
| **根因** | 详情页 `_formatTime(iso)` 写成 `DateTime.tryParse(iso)`，**漏了 `.toLocal()`**。`DateTime.parse` 遇到带 `Z` 的字符串会解析成 **UTC 时刻**（`isUtc=true`），此时直接读 `t.hour` 拿到的是 **UTC 小时**，而不是用户所在时区的小时 |
| **修复** | `DateTime.tryParse(iso)` → **`DateTime.tryParse(iso)?.toLocal()`**（一行），并在注释里写明口径（模型层留 UTC 便于比较，只在**格式化显示**时转本地）。展示格式 `YYYY-MM-DD HH:mm` 保持与列表页**逐字一致** |
| **回归证据** | 新增断言「**同一 UTC 输入 → 公告列表与详情两页显示逐字相等**」（`apps/boss-app/test/announcements_page_test.dart`）。该断言的设计要点：**期望值由 Dart 自己算**（`DateTime.parse(iso).toLocal()` 再格式化），**不是写死字面量** —— 否则两个页面可以"一起错"却仍然通过；并先断言 `本机时区非 UTC`（保证用例有鉴别力，CI 跑 UTC 时会退化） |
| **提交** | `7164ba1` |
| **备注** | 这条断言的取值路径是"先取列表页渲染出的时间文本，再进详情页取，两者必须逐字相等" —— **缺少 `.toLocal()` 时会红**（详情页会早 8 小时，`findsOneWidget` 落空） |

**修复后现状（我读文件确认）**：

```dart
// apps/boss-app/lib/pages/announcement_detail_page.dart:97-106
String _formatTime(String iso) {
  // ⚠️ 必须 `.toLocal()`：服务端下发的是 UTC（`2026-10-05T12:30:00.000Z`），
  // 少了这一步，同一条公告在**列表页**与**详情页**会显示成相差 8 小时的两个时间（实测东八区差 8h）。
  final t = DateTime.tryParse(iso)?.toLocal();
  if (t == null) return '';
  String two(int n) => n.toString().padLeft(2, '0');
  return '${t.year}-${two(t.month)}-${two(t.day)} ${two(t.hour)}:${two(t.minute)}';
}
```

### 2.4 【B3 · P3 · 已逐处核对，**时区清单里只该改 1 处**】全仓时区告警的**完整清单与逐处判定**

**背景**：主控初扫时把全仓 `DateTime.tryParse/parse` 未带 `.toLocal()` 的**15 处**（lib 侧）作为
"同类批量隐患"交给 B 路（主报告 2.1 表**第 4 行**；同表**第 3 行**是其中**真正上屏出错的那一处**——
公告详情页，已单独记为 P2 缺陷）。B 路**逐处核对**后给出结论：

> **除 2 处真正上屏的缺陷外，其余 13 处属"模型层解析"—— 正确地保持 UTC，不应改。**
> **理由**：`DateTime.parse('...Z')` 得到的是**带时区信息的 UTC 时刻**（`isUtc=true`）。把它当**数据**保存
> （用于**比较 / 排序 / 计算间隔**）时，**UTC 是正确且更安全的表示**（不同时区的两端比较结果一致）；
> 只有在**格式化成人看的文本**那一刻才该 `.toLocal()`。
> **若在模型层就 `.toLocal()`，会破坏时间比较与排序**（本地时间带 DST/时区偏移语义，跨时区或跨 DST 比较会错）。
