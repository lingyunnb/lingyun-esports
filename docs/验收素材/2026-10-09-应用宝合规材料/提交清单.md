## 三、电子版权认证 vs 普通软著（对比与建议）

### 3.1 材料差异对照

| 对比项 | 电子版权认证（电子认证通道） | 普通软著登记（中国版权保护中心） |
|---|---|---|
| 表单字段量 | 较简：以申请人信息 + 软件信息 + 源程序量为核心（本批 `电子版权认证-申请信息表.md` 已按"字段尽量全"整理） | 较全：另有开发方式、权利取得方式、权利范围、软硬件环境、编程语言等细项（本批 `软著申请表信息.md` 已逐项给值） |
| 源程序提交 | 多数场景只需提交**部分源程序**（常见为前 30 页 + 后 30 页）或按要求提供 | 同样要求前 30 页 + 后 30 页（每页 50 行），格式要求更明确 |
| 说明书 / 用户手册 | 常要求提交 | 必须提交 |
| 申请人身份材料 | 需要（个人身份证 / 单位营业执照） | 需要 |
| 权属证明 | 视情形（非独立开发时需提供） | 视情形 |
| 证书形式 | 通常为**电子证书**（是否可加发纸质证书、是否收费需以机构页面为准） | 通常为**纸质证书**（可申请电子版，具体以机构规定为准） |
| 办理渠道 | 线上为主 | 线上 + 线下窗口 / 代理机构 |
| 常见用途 | 应用商店上架、平台备案、快速证明权属 | 权属登记、维权诉讼、高企/项目申报、渠道资质 |

### 3.2 下证时长与费用

| 项 | 结论 |
|---|---|
| 下证时长 | **以机构页面为准**（不同机构、不同加急档期差异较大；本材料不作任何时长承诺） |
| 费用 | **以机构页面为准**（官方收费与代办服务费是两笔；本材料不作任何费用承诺） |
| 加急 / 普通档 | **以机构页面为准** |
| 需要准备的时间 | 取决于材料是否齐备：本批四份送审材料（源程序文档、说明书、两张信息表）已可直接使用；主要变量是负责人身份材料与签署流程 |

### 3.3 为什么建议后续补办软著

| 理由 | 说明 |
|---|---|
| 权属证明的通用性 | 《计算机软件著作权登记证书》是国内权属证明的通用形式，在维权诉讼、行政投诉、项目申报、投融资尽调中接受度最高 |
| 渠道与平台的兼容性 | 并非所有渠道、所有合作方都接受电子版权认证；拥有软著证书可避免"某个渠道只认软著"时被卡 |
| 材料可复用 | 本批材料（源程序文档、说明书、两张信息表、首次发表日期证据）与软著申请材料**高度复用**，补办时主要补"申请表 + 身份材料"，边际成本低 |
| 名称与版本一致性 | 先用电子版权认证完成渠道上架，再补软著时若期间改了名称/版本，需注意两证口径一致性（建议**先定名再同时申报**） |
| 风险对冲 | 若电子版权认证在渠道侧被要求补充说明，可立即用软著证书作为补充权属材料 |

**建议路径**：先以电子版权认证满足渠道上架时效 → 上架稳定后按同一软件全称与版本号补办软著登记（材料直接复用本批文档）。

### 3.4 主体选择建议（与"个人主体做不到的项"呼应）

| 情形 | 后果 |
|---|---|
| 以**个人主体**提审 | 承诺函用个人版可办；**ICP 备案截图的"加盖公章"做不到**；若渠道要求行业许可证，多数许可证不接受个人申请 → **很可能被卡** |
| 以**单位主体**提审 | 全部盖章类材料可办；但需统一"著作权人 = 备案主体 = 提审主体"，否则需提供授权书 → **需负责人确认主体归属** |

> **结论**：本批材料对**两种主体都适用**（承诺函有两版、信息表的申请人字段均为占位符）；但**"ICP 备案截图盖章""行业许可证"两类在个人主体下基本无法完成**，建议负责人在提审前先确认主体类型，再决定是否需要先注册/变更主体。

| 1 | 提审主体是**个人**还是**单位** | 决定承诺函用哪一版、哪些材料做得到 |
| 2 | 是否已有 **ICP 备案**，备案主体与域名 | 决定是否需要先备案、截图能否盖章 |
| 3 | 渠道是否要求**安全评估报告** | 决定是否需委托评估 |
| 4 | 渠道是否认定需要**特殊行业资质** | 决定是否需要许可证（个人主体通常无法申请） |
| 5 | 渠道当前实际资质字段清单 | 决定本清单的映射是否完整 |
| 6 | 首次发表日期口径（2026-09-22 已发表 / 未发表） | 影响两张信息表 |
| 7 | 软著全称与渠道应用名是否一致（是否需要名称不一致说明） | 影响是否要额外出一份说明 |
| 8 | 用户协议 / 隐私政策是否已在应用内可访问、是否需提供外链 | 影响渠道内容合规审核 |
| 9 | 未成年人保护提示文案 | 影响内容安全说明的填写 |
| 10 | 电子版权认证的具体机构与是否加办纸质证书 | 影响邮寄地址与后续材料 |
