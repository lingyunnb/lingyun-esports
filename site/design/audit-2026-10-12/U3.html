形态：YYYY-MM-DD HH:mm 今天 → 今天 HH:mm 昨天 → 昨天 HH:mm 缺失 → —
✓ 相对词只用在"今天 / 昨天"两天内，再往前一律给完整日期 —— 管理端要的是"这条是几点发生的"，而不是"3 天前"这种要心算的说法。
落点 加什么函数 format.ts
// admin-web/src/utils/format.ts（追加，与 formatYuan 同一文件） /** * 日期时间显示（管理端**唯一实现**） * 形态：YYYY-MM-DD HH:mm；今天/昨天用相对词；缺失/非法 → '—' * 与金额同思路：口径单点，禁止各页面自己 toLocaleString / padStart。 */ export function formatDateTime(v: string | number | Date | null | undefined): string; /** 表格用：缺失给占位符（默认 '—'，与 formatYuanOr 同款） */ export function formatDateTimeOr(v, placeholder = '—'): string; /** 只有日期没有时间时（榜单周期这类） */ export function formatDate(v): string; // YYYY-MM-DD
✓ 为什么放同一个文件：format.ts 已经是"管理端显示口径的唯一出口"， 日期与金额是同一类东西（都是"后端原始值 → 给人看"）。放一起，后人才不会另开一个 date.ts。

逐项口径

项内容
现状日期时间没有唯一实现：写法 A（toLocaleString('zh-CN')，18 文件 / 25 处，渲染成 2026/10/12 14:30:25）与写法 B（手写 padStart，5 文件，渲染成 2026-10-12 14:30）并存；缺失值占位符还有 '-' / '—' / '' 三种。
建议① admin-web/src/utils/format.ts 新增 formatDateTime(v) / formatDateTimeOr(v, placeholder='—') / formatDate(v)；

④ 逐页删掉本地 fmt / fmtTime 与内联 toLocaleString，改调新函数（约 38 处 / 15+ 文件）。
影响面不需要动服务端。纯展示层、零业务风险、不动接口与数据结构。
