与底部凸起「祁小山」的关系处理（同屏不打架）

同一屏右下角同时存在两个动作体：中间凸起（⌀54、白底、发丝线、祁山标、top:-16、居中 → 进 AI 分支） 与 下单浮标（right 16 → 进下单页）。四个可用手段：①尺寸差、②形状差（正圆 vs 胶囊）、 ③色相 / 明度差、④垂直抬高（浮标整体抬到凸起顶边之上，或与之错开足够横向净距）。 共同前提：绝不与凸起重叠 —— 五套方案的浮标底边都落在 y≤744（凸起顶边）之上； 横向净距 A 60dp / B 108dp / C 104dp / D 104dp / E 24dp（E 是最扁最宽的一个，靠 16dp 垂直让开兜底）。

推荐
