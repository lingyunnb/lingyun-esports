## 六、结构规则 1 核对（「同一入口只出现一次」）

**规则原文**（`CLAUDE.md:99`）：底部导航已有「服务 / 订单 / 消息 / 我的」→ 顶部导航**不再出现这几个名字**；顶部只放底部没有的。

**底栏实际五项**（`app_nav.dart:153-159` + `:192-201` 的标签）：**服务 · 订单 · 祁小山（中间凸起）· 消息 · 我的** —— **没有「选择陪玩」，也没有「找陪玩」**。

**结论①**：把「选择陪玩」放进顶部导航，**不在**规则 1 那四个名字之内 → **不违反**。

**结论②（本轮的额外发现）**：底栏中间凸起按钮的**长按**会弹出 `AppQuickActionsSheet`，里面第一项就是「找陪玩」→ `_openPlayers`
（`home_shell.dart:234-239`、`app_nav.dart:922-928`）。这是**不显形的第二条入口**。
→ **甲方案（移除面板项）已被负责人采纳**：入口由顶部导航**单一承担**；`docs/14` 补记「快捷面板是快捷方式，不计入入口唯一性」。
→ ⚠️ 与第三节的**耦合**同源：移除与新增必须一次提交。
