# A 案详解（极简留白）


## 一、设计方向（负责人要求：简约大气、上档次）

**一句话**：**少即是贵** —— 去掉一切"特效感"（玻璃、光斑、渐变堆砌、炫光描边），改用**排版层级 + 留白 + 分层阴影**表达高级感。

参考对象（均为公开设计规范/开源项目，按负责人 2026-10-03 授权可照抄）：

| 参考 | 抄什么 |
|---|---|
| [Apple HIG（8pt 网格 / Dynamic Type）](https://developer.apple.com/design/human-interface-guidelines/layout) | 间距刻度、16pt 页边距、字号层级、触控区 ≥44pt |
| [Linear](https://linear.app) / [Vercel](https://vercel.com) 式克制 | 近黑墨色文字、单一强调色、边框极淡、阴影分层克制 |
| [shadcn 风格（flutter-shadcn-ui 模板）](https://www.shadcn.io/template/nank1ro-flutter-shadcn-ui) | 卡片 = 白底 + 1px 极淡边 + 轻阴影；胶囊选择器；分组列表 |
| [Best-Flutter-UI-Templates（22.8k★）](https://github.com/mitesh77/Best-Flutter-UI-Templates) | 首页区块节奏、横滑卡片、数据卡布局 |
| [flutter_miuix](https://pub.dev/packages/flutter_miuix)（已接入，Apache-2.0） | 组件底座（按钮/输入/开关/列表项），保留 |

**明确去掉**：液态玻璃主题的满屏模糊与光斑背景、渐变描边卡片、彩色宫格高饱和底色的滥用、emoji 当图标。

## 二、设计 token（三端统一）

### 色彩
| 用途 | 值 | 说明 |
|---|---|---|
| 主文字 | `#0C0E12` | 近黑（比纯黑更"贵"） |
| 次级文字 | `#565C68` | |
| 三级/说明 | `#8A909C` | |
| 强调色 | `#3D5AFE` | 单一强调色，全局仅此一处高饱和 |
| 强调浅底 | `#ECF0FF` | 选中底/标签底 |
| 分割线 | `#E9ECF2` | 1px |
| 页面底 | `#FFFFFF` / 分区底 `#F6F7FA` | |
| 状态色 | 成功 `#16A34A` / 进行中 `#EA7A14` / 危险 `#DE3838` / 金 `#B0842E` | 仅小面积使用 |

### 字号层级（Dynamic Type）
| 层级 | 规格 | 用途 |
|---|---|---|
| 大标题 | 25 / 700 | 页面标题（我的、下单、接单大厅） |
| 区块标题 | 18 / 700 | 首页区块 |
| 卡片标题 | 15.5 / 700 | 商品名、订单名 |
| 正文 | 13 / 400 | 描述 |
| 辅助 | 11.5 / 400 | 时间、区服、次要信息 |
| 说明 | 10.5 / 400 | 标签、单位 |

### 间距 / 圆角 / 阴影
- 间距：4 / 8 / 12 / 16 / 24 / 32（8pt 网格），页面左右边距 **16**
- 圆角：卡片 16–20、胶囊 999、弹层 24、图标块 12
- 阴影三层：**L1 列表卡** α16 y4 blur14 / **L2 浮起卡** α26 y8 blur20 / **L3 弹层** α44 y10 blur30
- 动效：160–260ms `easeOutCubic`，只做淡入/位移，不做弹跳炫技

### 图标
线性描边 2pt、圆角端点；**禁止 emoji 当图标**（现有代码里 👑🎧 之类全部替换为线性图标或矢量绘制）。

## 三、页面级改法（保留功能与接口，只改呈现）

### 老板端
1. **首页**：大标题「祁连山电竞」+ 问候 → 账户卡（深靛渐变，积分余额 + 去下单）→ 2×2 功能卡（白底极淡边 + 浅色图标块）→ 优秀打手横滑（头像 / 评分 / 立即下单）→ 公告（单行 + 日期）
2. **下单**：游戏胶囊 → 分类胶囊（选中=近黑实底）→ 商品卡（左图 68×68 / 商品名 / 一行说明 / 价格大号 / 立即下单）→ 右下客服悬浮按钮
3. **订单**：状态胶囊（选中=近黑）→ 订单卡（商品名 + 状态色标签 / 分割线 / 区服 / 打手 / 金额 / 次级按钮）→ 底部详情弹层（圆角 24 + 拖拽条 + 信息键值对 + 主操作）
4. **我的**：通顶渐变头部（大标题 + 头像 + 昵称 + 等级胶囊 + ID）→ 数据卡压头部下沿（积分/累计消费/订单数）→ 分组列表（图标块 + 标题 + ›）→ 版本号

### 工作端
1. **接单大厅**：大标题 + 在线状态点 → 收益卡（墨绿渐变，本月收益 + 评分/今日完成/进行中）→ 分段（大厅 / 我的订单）→ 单卡（商品×数量 / 单价·总额 / 分区标签 / 时间 / 立即抢单）
2. **排行榜**：白底榜单，前三名用金/银/铜细边圆标，其余为序号；周期切换用胶囊
3. **我的**：与老板端同一套骨架（渐变头 + 数据卡 + 分组列表）

### 管理后台 / 官网
- 管理端：沿用现有 Naive UI，仅统一 token（主色 `#3D5AFE`、卡片圆角 16、表格行高与分割线颜色），不做结构重写
- 官网：字体层级与按钮样式对齐 App（现有深色风格保留）

## 五、不改的东西（安全线）

- 所有接口、数据结构、权限校验、积分与订单规则**一律不动**（纯 UI 层改动）
- 客户端数据不可信原则不变；不新增任何客户端可信参数
- 现有测试必须继续全绿（老板端 14 / 工作端 13 / core 32）；改完真机验证

## 六、实施顺序（审批通过后）

1. `fish_core` 设计 token 重写（颜色/字号/间距/圆角/阴影/动效）→ 三端共用
2. 组件层：`FishCard`（L1/L2/L3 阴影）、`FishButton`（主/次/文字）、`FishChip`（胶囊）、`FishListGroup`、`FishIcon`（线性图标集）
3. 老板端逐页改造：我的 → 首页 → 下单 → 订单 → 消息/聊天 → 二级页
4. 工作端逐页改造：大厅 → 订单 → 排行榜 → 我的 → 消息
5. 管理端 token 对齐（小改）
6. 回归 + 真机验证 → 发布双端（发布铁律）→ 推装负责人手机

## 七、需要负责人确认的点

1. **方向是否认可**：极简克制（近黑 + 单靛蓝 + 分层阴影），彻底去掉液态玻璃？
2. **强调色**：`#3D5AFE`（靛蓝）是否符合预期？或指定色值（如品牌墨绿/金）
3. **主题开关**：现有"初始主题 / 液态玻璃"两套主题，是否直接砍掉液态玻璃只留新设计？
4. **老板端首页结构**：账户卡 + 功能宫格 + 优秀打手 + 公告，是否还有其他要上的区块？
