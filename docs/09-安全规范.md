# 09 - 安全规范

## 威胁模型

所有来自客户端（Flutter App / 浏览器）的数据一律不可信。攻击者可直接调用 API、篡改参数、重放请求、并发轰炸。服务端是唯一权威。

## 编码禁令（违反即返工）

| 禁止 | 正确做法 |
|---|---|
| 信任请求体/路径参数中的 userId/workerId/管理员 id | 主体 id 只从 JWT sub 取 |
| 信任客户端传来的价格/余额/积分 | 服务端查库定价与校验 |
| 信任客户端传来的订单状态/权限 | 状态机 + RBAC 服务端校验 |
| 拼接 SQL 字符串 | TypeORM 参数化查询 |
| 硬编码密码/密钥/Token | 环境变量（.env，不入 git） |
| 生产环境 synchronize=true | 一律 migration（docs/10） |
| 无归属条件的资源查询 | 强制 WHERE user_id=当前主体 |
| 返回 password_hash/密钥等敏感字段 | DTO 显式控制输出 |
| 上传文件信任客户端文件名/MIME | docs/08 三重校验 |
| 无限流的关键接口 | 登录 5 次/分；WS 20 条/分；全局阈值 |

## 防护清单

- **IDOR/越权**：见 docs/04 越权自测用例
- **重复提交**：幂等键唯一约束（下单/积分发放）
- **并发扣款**：条件更新 + 事务（docs/06）
- **请求重放**：JWT jti 登记 + 撤销校验；敏感操作记 request_id
- **暴力破解**：登录限流 + login_log 分析
- **SQL 注入**：参数化查询；全量 payload 自测（M8）
- **XSS**：管理后台 v-html 禁用；富文本输出白名单（M2 商品描述）
- **CSRF**：JWT 存内存/安全存储，非 Cookie；管理后台登录态同源校验
- **恶意上传**：docs/08
- **WebSocket 越权**：docs/07 房间归属校验
- **敏感信息泄露**：全局异常过滤器不返回堆栈；日志脱敏（密码/Token）

## 安全自测清单（每个里程碑完成时勾选，M8 全量执行）

- [ ] 普通用户调管理员接口 → 403
- [ ] 工作端伪造 workerId → 403
- [ ] 用户伪造 userId → 403
- [ ] 修改订单 ID/商品 ID → 无效
- [ ] 修改价格/积分/余额参数 → 无效
- [ ] 修改订单状态参数 → 状态机拒绝
- [ ] 重复请求/同幂等键并发 → 仅一次生效
- [ ] SQLi payload（' OR 1=1 等）→ 无效
- [ ] 路径穿越（../../etc）→ 无效
- [ ] 伪造扩展名/超大小上传 → 拒绝
- [ ] 越权 join 聊天房间 → 拒绝
- [ ] 无接单/客服权限调接口 → 403
- [ ] 普通管理员发放积分/授接单权限/改最高安全配置 → 403

## 审计

- operation_log：管理员敏感操作全量留痕（模块/动作/路径/脱敏请求体/IP/requestId/结果）
- login_log：成功与失败登录
- 安全审计页（M8）：失败登录、越权尝试（403 聚合）、权限变更、积分操作、会话授权变更
