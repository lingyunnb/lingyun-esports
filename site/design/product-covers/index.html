00调研依据（地铁币与变卖物的实际特征）

设计前先做了实物调研：搜索并下载参考图后逐张看图，把"地铁币 / 变卖物实际长什么样"写成可核对的描述， 再据此自绘。参考图仅用于理解特征，成品零位图（见 §03 合规自证）。

地铁币的实际外观（有实拍图佐证）

  • 不是圆形硬币：是3/4 俯视的矩形金色物件（读作金条／一叠钞票形态），有四个倒角边。
  • 下方露出一条"第二层"薄边，所以看起来像"叠着的一层"，而不是一块实心砖。
  • 表面有深色横向花纹（两道短横 + 一道长横），左端面有平行刻线。
  • 配色：主体亮金／奶油金（近 #FDE68A），暗部深琥珀（近 #B45309）。
  • 数量与名称在游戏里是白色粗体数字在图标下方（实拍见 30000 / 地铁币 的排布）。
  • 游戏内物品面板底色是深蓝紫，琥珀金只用于"价值/金额"文字 —— 这也是本设计把琥珀金专留给价格与数字的原因。

变卖物的真实品类与外观

  • 查到并看图确认的品类：飞机雕像（6 周年纪念，橙红底图标、价值约 66 万）、 群狼宝冠（金冠 + 红宝石，宣传图级别）、金龙／龙形金器、 金丝大棉被（游戏内售价 $588,888，纯金色）、 特种部队头盔（3 级，头部减伤 55%）、警用防弹衣（2 级，减伤 45% / 容量 +50）、 显卡／硬盘／加密币／情报／钥匙 一类深色矩形电子件与卡片。
  • 共同视觉规律：高价变卖物基本是"大块金色／黄铜色立体器物"，体量大、轮廓复杂、金属反光； 深色小矩形则是低价的电子件/卡片类。
  • 游戏内售价写法：金色大号数字 + $ 前缀 + 千位逗号（如 $588,888）。
  • 据此，方向 B 的"资产堆叠"选用 金条 + 硬币 + 保险箱 三类几何化表达： 它们覆盖了"贵金属 / 通货 / 容器"三种真实资产形态，而且都能用纯几何块画准（不描摹官方美术）。

「保底 200w」「不卡保底」的语义

  • w = 万：200w = 200 万，此处单位是地铁币（地铁逃生模式内的通货）。
  • 保底：代练/陪玩行业通用用法是"承诺一个最低结果"；在搜打撤玩法里即 "账号资产至少带到 200 万地铁币"。行业里"保底收益"是被投诉过的宣传点 （有消费者投诉平台以"虚高装备价值结算"拒绝退款），所以本稿把它写成可验证的动作： 「一局内带出到账，未达 200w 按约定补带」，而不是含糊的"稳定收益"。
  • 不卡保底：查到的公开资料里没有权威定义。保守处理：按行业最通行的两种理解写成 「不加价、不设隐藏门槛」——即不会因为打到保底就临时加价或设附加条件， 并不声称"必定达成"。此条需负责人确认（见"未做/风险"）。

01三套设计（方向不同，不是换色）

A · 数字主导

推荐 整幅深色海报

做法整幅近黑实色（#0F172A）单底色，不放分栏；右上版块全部让给 琥珀金「200w」（字号按可用宽度自动收敛到约 0.92 栏宽），下接一道琥珀实色下划线 + 「保底地铁币」； 底部一条价格带：左侧琥珀「9.9 元 / 99 积分」块，右侧「董事长推荐」块。

为什么封面第一眼必须看到"保底 200w"这个数字。把整幅压成单一深底、 把唯一的亮色大块给数字，是让数字成为绝对主体最省装饰的做法 —— 也是删掉左右分栏的原因： 分栏会在画面中间留纵缝，且两栏中段都空。

元素的信息意义右上角自绘地铁币 + 「地铁逃生 · 计价单位」＝ 说明 200w 是什么单位； 左下三行＝交付口径；价格带＝价与积分。
