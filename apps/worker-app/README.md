## 废除口径（负责人 2026-10-06 拍板，照此执行，不要自行加码）

| 项 | 状态 |
|---|---|
| 工作端 App | **已废除并已完全阻断** —— 终版 **v1.8.0（码 58）** → 到期自动阻断 v1.8.1（码 59） → **完全阻断 v1.8.2（码 60）**，废除日期 **2026-10-06**，代码保留、**停止更新** |
| 工作端代码 | 保留（**不删任何页面**，接单/抢单/收益/聊天逻辑一字未动） |
| 云端更新通道 | `worker` 通道保留（**这样还开着旧版的人一打开就收到这个阻断版**），当前 **v1.8.2（码 60）** |
| **服务端 worker 模块** | **必须保留，一行都不能动** |
| **打手账号与角色** | **必须保留**（账号、角色、接单/客服权限、`worker_division_permission` 全部照旧） |

**为什么服务端与账号必须留**：老板端「打手态」是**伴随会话（companion）**在调 `/worker/*` 接口，
权限判定（`worker_division_permission`、接单/客服权限）就是打手态的权威依据；删掉任何一处，打手态当场失效。
详见根 `CLAUDE.md` 结构规则 11 与 `docs/04-认证与授权规范.md`。

## 当前行为（v1.8.2 / 码 60 = 完全阻断版）

1. **打开 App 先出阻断页，进不去主界面**（`lib/pages/worker_sunset_block_page.dart`，与既有强制更新阻断同一套机制）：
   「工作端已停止服务，请下载「祁连山电竞」App，在「我的 → 身份」里绑定打手账号后继续接单。」
   + 下载入口（地址明文 + 一键复制，不加依赖、不假装能开外链）
   + 5 步绑定（文案用老板端真实控件名：切换身份 / 打手端账号 / 绑定并切换为打手 / 切回老板）。
   底部**只剩「前往下载」**——「暂时继续使用」那条分支在 `kWorkerSunsetBlocking = true` 下永不渲染。
2. **首页/我的引导条**（`lib/widgets/migration_notice.dart`）与阻断页**共用同一句常量**（现在时、**不带日期**）；
   v1.8.1 的「将于 10 月 13 日停止服务（还剩 N 天）」倒计时整行与倒计时函数**已删除**
   （立即生效还说"将于某日停止"= 让人以为还有时间）。
3. **业务一行未动**：接单/抢单/收益/聊天、排行榜、消息等既有逻辑与页面全部保留。
4. **服务端兜底仍在**（本轮**未改服务端**）：`system_setting.worker_app_sunset_at`
   （线上默认 `2026-10-13 00:00` Asia/Shanghai）到期后拒绝 `role=worker` 的 **primary** 会话
   （登录 403 / 请求 401 / WS 拒连）——给"别处还开着的旧版本"兜底；**打手态 companion 一律不受影响**。
   客户端**不再展示这个日期**（用户可见文案只说明"旧版本入口也会被关闭"）。

## 唯一开关

`lib/widgets/worker_sunset.dart`：

```dart
const bool kWorkerSunsetBlocking = true; // 本版 = 完全阻断（立即生效，任何时间都不可继续）
```

改回 `false` → 回到 v1.8.1 的"到期日自动阻断 + 到期前可暂时继续使用"老口径
（日期常量 `kWorkerSunsetReleaseDate` / `kWorkerSunsetGraceDays` / `kWorkerSunsetDate` 仍在同一文件；
判定纯函数 `workerSunsetCanContinue(now, {blocking})` 的 `blocking` **可注入**，
所以那条备用分支的回归覆盖一直留着）。
