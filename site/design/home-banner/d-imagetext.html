规格与理由（每个数字都要能说出理由 —— docs/21 第六节第 4 条）

项取值理由
槽位位置同 A（欢迎语行之下、「选择分部」之上）D 是 A 的"信息增强版"：位置相同、框体不同，运营可以按活动类型（纯图 vs 需要文案+按钮）在管理端选布局
卡片尺寸358 宽；图 140 + 白区 72 = 总高 212信息型活动位需要一行标题 + 一行副信息 + 一个按钮，白区 72 是这三样的最小可行高度（11+18+4+15+12）
圆角10（外层卡）/ 0（图与白区之间）D 是"信息卡"不是"整块图"，回到卡片档 10；图与白区之间不分缝、不各自圆角（那是模板签名）
指示器图内右上角「1/3」细描边胶囊底部被白区占用；用计数而不是圆点，是因为 D 的图会被卡内边距裁切，计数比圆点更抗素材干扰
按钮「去看看」实色主色 #2563EB / 圆角 6 / 12pt w700docs/21：说清动作与结果 —— "去看看"指向明确（去看这个活动/商品），比"了解更多"具体
切换动画位移 + 吸附，320ms easeOutCubic同 A
自动播放默认关闭，管理端可开（5s）D 有文案需要读，自动播放会打断阅读 → 更应默认关闭
循环是同 A
单张时不显示计数；白区保留见上
空态整槽不渲染（高度 0）见上
与浮标/底栏关系无冲突D 最高（212），「选择分部」标题落在 y≈420，首屏仍能看到通栏主分部卡；五张分部卡大部分需要在首屏外滚动

与 docs/21 逐条对照

docs/21 条款结论落地方式
禁渐变做主视觉符合示例为实色主色底图 + 纯白信息区，无渐变
圆角分档符合外层 10、按钮 6、计数胶囊 4
禁阴影铺满符合卡用 1px 发丝线；图与白区之间用留白而不是分隔线（信息层级靠留白就够）
无 emoji / 装饰插画符合同 A；按钮无图标装饰
文案具体可验证符合标题「周末双排护航 8 折」+ 副「10/05–10/07 · 全分部可用」；按钮"去看看"指向明确
信息型活动位的反 AI 味风险需负责人拍板图 + 标题 + 按钮是电商 Banner 的统计中位数形态，最容易被看成模板。缓解：① 不放大圆角、不加阴影；② kicker 小片用细描边而不是彩色胶囊；③ 标题不做成"主标题+副标题+标签+按钮"四件套，只保留三件

顺序决策（与既有元素的关系）

顶部导航 → 投诉/打赏/退款 → 欢迎语行 → 宣传图（D） → 选择分部 → 祁连山官方
  • 与「投诉/打赏/退款」三宫格：宣传图始终在三宫格之后。三宫格是"订单相关操作入口"（投诉/打赏/退款），属于工具行；工具行贴顶是这类 App 的共同习惯，也是 docs/21"顺序按业务需要"的直接体现 —— 用户找退款时不该先划过一张活动图。
  • 与"欢迎语行"：宣传图在欢迎语行之后。欢迎语行只有 2 行 11.5pt 小字、高约 40pt，承担"这是官方自营"的心理铺垫；把它压在宣传图上方等于用一张活动图打断"导航 → 操作入口 → 品牌问候"的三拍节奏。
  • 与「选择分部」：所有方案宣传图都在「选择分部」之前。理由：宣传图是转化前的活动耳语（不参与下单主路径，不产生分支），而「选择分部」是主路径的第 0 步。活动位放在主路径之前，是"看一眼活动 → 进入正事"的自然阅读顺序；放在分部卡之后就变成"下完单才看到活动"。
  • 不与右下「立即下单」浮标打架：浮标固定在 right:16 / bottom:96，宣传图在最上方，纵向完全不重叠；宣传图不做横向全屏手势区（滑动只在自己的框内），不会抢浮标的点击。
  • 不与底部凸起「祁小山」打架：凸起位在底栏中间（bottom:30 + 54pt 圆 + 上方 26pt 标签），属于最底部 60pt 区域，与顶部宣传图相距 > 600pt；宣传图的自动播放也不覆盖底栏（不是全屏浮层）。

交互规格（给实现用）

  • 滑动：横向整页吸附（Flutter PageView），松手吸附最近整页；过渡 300–320ms easeOutCubic。
  • 循环：首尾相接（末页右滑回首张）。实现建议：页数 > 1 时用 itemCount = n + 2 的哨兵页，或直接不加循环（3 张的活动位循环不是必须，需负责人定）。
  • 自动播放：默认关闭；管理端可开（间隔 5000ms）。用户手指按下即暂停、松手 8s 后恢复（这是行业通行做法）。
  • 点击：link_type = none 时整卡不可点（不给"假可点"反馈）；其余类型整卡可点 + 按下的轻微透明度反馈（opacity .92，不做缩放动画）。
  • 加载态：358×163 的浅灰 #E7EEFE 圆角块，不闪、不做 shimmer（docs/21：不做炫技动效）。
  • 错误态：与页面其它接口一致 —— 宣传图拉取失败静默不显示（首页不该因为一个活动位而出现错误卡）。
