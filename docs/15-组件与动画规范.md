# 15 - 组件与动画规范

## 组件清单（三端统一视觉语言）

| 组件 | 规范要点 |
|---|---|
| 按钮 | 主按钮 primary 底白字；次按钮白底描边；危险操作红色；禁用态明确 |
| 输入框 | 白底、圆角 8、聚焦主色描边、错误态红描边+提示 |
| 卡片 | 白底圆角 12、无重阴影（0 1px 4px rgba(0,0,0,0.04)）、间距留白 |
| 列表项 | 头像/图标 + 标题 + 次级信息 + 右侧操作，行高呼吸感 |
| 标签 | 状态标签色点+文字（订单状态/服务状态） |
| 弹窗 | 居中、遮罩 rgba(0,0,0,0.4)、内容克制、危险操作确认 |
| 骨架屏 | 内容占位浅灰块，加载时替代转圈（列表/详情） |
| 空状态 | 图标+一句话+引导动作，不堆装饰 |
| 错误态 | 文案说明+重试按钮 |

## 动画原则（每条动画先回答：是否帮助理解操作/状态/关系？不能则不添加）

- 时长 **200~300ms**，缓动自然（ease-out 为主）；影响操作速度的动画取消
- 适用场景：页面进入/退出、卡片出现、按钮反馈、下单成功、订单状态变化、消息出现/发送、弹窗、加载、骨架屏、排行榜变化、图片切换、商品详情展开、头像资料变化、错误提示、成功反馈
- **禁止**：无限循环炫技动画、大量粒子、过度缩放、过度弹跳、快速闪烁、强烈视觉干扰
- 低性能设备必须基本流畅；列表滚动禁止重动画

## 交互反馈

- 可点击元素必须有反馈（按压态/涟漪 200ms）
- 表单提交有 loading 与防重复点击；成功/失败有明确提示
- 发送消息：发送中/已发送/已读/失败重发四态可见
- 订单状态变化有过渡动画 + 明确文案
