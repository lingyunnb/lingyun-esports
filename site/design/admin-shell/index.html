示意说明：图标位为线性图标（此处以内联 SVG 代位，实际为同一套线性图标，不用 emoji）；数字为拟真假数据，页面本身走现成接口。

折叠态（64px 图标条）：点父项 = 先展开侧栏、再展开该组

  • 点父项：先展开侧栏（220px），再展开该组 —— 一次点击就能看到子项，不存在"点不到的子项"。
  • 刻意不做浮层弹出菜单：浮层在 overflow:hidden 的侧栏里要 teleport、要自己管定位与"点击外部关闭"，多出一整套状态；"点一下先展开侧栏"零额外状态。
  • 选中态：折叠态没有 3px 主色条的空间，改用整块淡蓝底（rgba(37,99,235,.10)）表达当前项。
  • 展开态落 sessionStorage：是"这次办事要看哪几组"的过程状态，不是长期偏好；没存过时默认展开前 3 组（订单与售后 / 用户与身份 / 资金与抽成），当前路由所在组恒兜底展开。
  • 权限联动：父项自身不带权限点；子项按权限点过滤，子项全不可见 → 父项整体隐藏（不渲染空组）。

排版规格（示意已按比例缩小，实际 44px）

  • 全屏纯黑底 #000（刻意不用页面近黑——要的就是"全屏纯黑"），盖住侧栏 / 顶栏 / 内容区。
  • 居中、44px / 字重 800 / 白字（宽度 ≤1366 时降到 40px 防换行），两行间距 20px。
  • 下方一条 64px 宽 2px 高的冰雪蓝细线（#2563EB，唯一点缀）。
  • 没有插画 / 光斑 / emoji（docs/21 反 AI 味硬规则）。

文案与节奏的唯一出处

  • 文案常量：admin-web/src/constants/welcome.ts——页面里不许内联任何一句欢迎文案，改字只改这一处（逐字照用，不改字、不改标点）。
  • 节奏常量 WELCOME_TIMING + 总时长 WELCOME_TOTAL_MS（分段相加）同在这一个文件；全屏覆盖层在 components/WelcomeSplash.vue。
  • 可跳过：点击任意处 / 按任意键立即结束（避免每次登录都干等）。
本页为静态设计预览（纯 CSS / 内联 SVG 示意，无外部依赖、无第三方素材、无真实数据）； 色值与节奏与 admin-web 实现一致，权威文字以 docs/14-UI设计规范.md「管理端外壳（2026-10-11 定案）」为准。 反 AI 味自检：无 emoji、无装饰插画、无渐变主视觉（仅卡顶 3px 一处小面积渐变）。
