> **本文件是本次所有品牌化设计图的唯一基准。** 每个设计稿必须逐条遵守，产出后需自检并列出使用清单。
> 状态：**待负责人审批**（主色/Logo/辅助图形三项为推荐值，选定后仅需改 token 值，设计结构不受影响）

## 〇、品牌定位

- **品牌名**：祁连山电竞
- **定位**：专业、可靠、精致的游戏服务俱乐部
- **气质**：高端 · 简洁 · 稳重 · 有品质 · 有辨识度
- **设计目标**：让用户感到"这是经过认真设计和运营的商业品牌"，不是模板拼装
- **⚠️ 硬前提**：**「祁连山」只是品牌名，不代表要用山脉/雪山/山峰/户外风景做视觉主题**。
  品牌特色由 **标识 · 色彩 · 字体 · 图形语言 · 卡片 · 细节** 共同建立。

## 一、色彩体系（**核心：不用通用蓝**）

现状 `#2563EB` 是 Tailwind 默认蓝（"像模板"的头号原因）。本次换为**墨蓝 × 青瓷**。

| 角色 | 色值 | 用途 | 备注 |
|---|---|---|---|
| **品牌锚（墨蓝）** | `#0F2440` | 品牌区 / 深色块 / HeroCard 底 | 大面积稳重 |
| **主交互** | `#1D5FA8` | 按钮 / 选中 / 链接 | 白字对比 ≥5:1 |
| **强调（青瓷）** | `#0E7C7B` | 次级强调 / 成功 / 选中描边 | 沉静、专业 |
| **价格 · 等级** | `#B4732A` | 金额 / 等级徽章 | **全站唯一"金"，低饱和** |
| 页底 | `#F4F6F9` | 页面背景 | 冷灰蓝 |
| 卡面 | `#FFFFFF` | 卡片 | |
| 发丝线 | `#E3E8EF` | 分隔线 | **1px** |
| 正文 | `#14202E` | 主要文字 | 近黑蓝 |
| 次要 | `#4A5A6E` | 辅助文字 | |
| 弱化 | `#8A99AB` | 占位 / 时间 | |

**功能色**：成功 `#0E7C7B` · 警示 `#B45309` · 错误 `#B42318` · 信息 `#1D5FA8`
**页面浅底（同色相极浅档，用于标签/图标底）**：主色浅 `#E8EEF7` · 青瓷浅 `#E3F0EF` · 琥珀浅 `#F7EDE0`

**用色铁律**
1. **渐变面积 ≈ 0**（`docs/21` 已禁"渐变做主视觉"）→ 品牌区一律用**实色深块**
2. **深色块只出现在两处**：品牌区 + 每屏最多 1 个 HeroCard；其余保持大量留白
3. **价格/等级只用 `#B4732A`**，不出现第二个金
4. 状态**不能只靠颜色**区分（必须配形状/字重/图标/文案之一）

## 二、品牌辅助图形（**克制三件**，从 0 建立）

| 元素 | 做法 | 用量约束 |
|---|---|---|
| **① 斜切角（主符号）** | 卡片 / 标签 / 按钮的角部做 **45° 小切角 4–6dp**（通常只切 1–2 个角，如右上+左下） | 每屏 ≤ 4 处 |
| **② 细网格** | 1px 网格，**透明度 3–5%** | **只用于品牌区与空态**，正文区禁用 |
| **③ 标尺线** | 1px 发丝线 + 端点 **3×3 小方块** | 用于区块分隔 |

**明确禁止**：闪电 · 密集霓虹 · 发光堆砌 · 粒子 · 星空 · 装饰插画 · 卡通吉祥物

---

## 三、品牌标识（Logo）

- **主标识 =「祁」字标**：提纯为一枚**几何字标**（**去掉山形**）
- 写实雪山**降级为辅助纹理**（大尺寸 + 低透明度，**只做背景**）
- **不得**把写实雪山缩到小尺寸当图标用（5 层细节在 48dp 下必然糊）
- Logo 出现位置：品牌区左侧 / 启动页居中 / 管理端侧栏顶端
- **不使用**：山峰剪影、雪帽、游戏手柄、星芒 等组合图案

## 四、字体体系（7 级）

| 级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| Display | **22** | 800 | 页头大标题 / 品牌区主标题 |
| Title | **18** | 700 | 区块标题 / 卡片标题 |
| Subtitle | **15** | 600 | 列表主文案 / 商品名 |
| Body | **13** | 400 | 正文 |
| Caption | **12** | 400 | 辅助说明 |
| Micro | **11** | 400–600 | 标签 / 时间 / 角标 |
| 金额数字 | 15 / 18 / 22 | 700 | **等宽数字（tabular figures）** |

- 字体族：**MiSans**（老板端已生效；工作端需补 fonts 资源）
- **禁止**：同层级出现两种字号；字号不得少于 10.5

## 五、图标体系

- **单套**：全部用 `AppIcon`（**Flutter 内置 Material outlined**），**禁 emoji、禁拟物、禁彩色图标**
- **尺寸只 4 档**：`16` / `20` / `24` / `28`
- **选中态只一种**：线性 → **主色 + 字重加粗**（不做填充/发光/描边三套并行）
- 颜色：默认 `#4A5A6E`，选中 `#1D5FA8`，弱化 `#8A99AB`

---

## 六、卡片体系（**三档，打破"全是白圆角矩形"**）

| 档 | 形态 | 用途 | 每屏数量 |
|---|---|---|---|
| **HeroCard** | **墨蓝 `#0F2440` 实色块** + 斜切角 + 细网格纹理 + 白字 | 品牌区 / 主推商品 / 核心服务 | **≤ 1 个** |
| **ContentCard** | 白卡 · 圆角 **14** · 1px 发丝线 · 无阴影 | 常规内容 | 多个 |
| **ListCard** | **无圆角**分组 + 发丝线行（行高 52–56） | 列表 / 设置 / 表单 | 多个 |

- **圆角只允许**：`4–6`（小片）/ `10`（控件）/ `14`（卡片）/ 胶囊
- **禁止**：全大圆角（≥16 当卡片）/ 阴影铺满 / 每张卡都长一样

---

## 七、动效体系

- **时长只 3 档**：`120ms`（点击反馈）/ `200ms`（状态变化）/ `320ms`（页面切换）
- **曲线 2 条**：`standard`（easeOutCubic）· `emphasized`（进入/切页）
- **禁止**：回弹（`easeOutBack`）用于常规交互（仅"成功反馈"可用）· 复杂编排动效 · 为炫酷牺牲流畅度

---

## 八、内容真实性铁律

- 所有**商品 / 价格 / 服务说明 / 订单 / 会员 / 收益**数据**必须来自真实业务**，**不得写死虚假内容**
- 拟真示例必须符合真实业务口径：
  - 金额：`¥28.88` / `¥115.52` / `¥4,286.50`（**`¥` + 两位小数 + 千分位**）
  - 分部：`和平精英 · 手游` / `三角洲行动 · 手游` / `三角洲行动 · 端游` / `无畏契约 · 手游` / `无畏契约 · 端游`
  - 商品名来自真实目录（如 `9.9新人体验单保200w不卡保底`）
  - **禁止**"示例文本1/2/3"、"xxx"、"待定"
- **全站不得出现「积分」**（2026-10-09 起计价单位为「元」）；**不出现「我的排名」**（老板端无个人名次）
- **玩家圈已下线**（不出现）；**语聊房已暂停**（不出现）

---

## 九、结构规则（CLAUDE.md，不可违反）

1. **同一入口只出现一次**（底部导航已有的，顶部不再出现）
2. **不存在的东西不出现**（未绑定打手 → 不显示切换入口；无图 → 不显示空框）
3. 底部导航 = **服务 · 订单 · ＋下单 · 消息 · 我的**
4. 每行陪玩/打手**只有 名次/头像 + 名字 + 数值**（不写分部、不带标签）
5. **不做**奖杯插画、并排三个大数字

## 十、设计稿交付要求（每份都要满足）

- **自包含 HTML**：纯 CSS + 内联 SVG；`<img>`=0、`<script src>`=0、`@import`=0、外部 `http` 链接=0
- 手机壳按 **390×844 逻辑像素**渲染，并排图宽度 **≥1200** 便于评审
- 每份必须画出：**首屏（不滚动）** + **滚动后完整页** + **加载骨架态**
- 每份必须附**自检数字**：渐变面积 · 阴影处数 · emoji 数 · 字号种类数 · 金额格式违规数 · 「积分」出现次数 · 卡片档位使用情况
- 每份必须附**简短方案文档**：现状问题（带行号）· 改造点（带行号）· 红线核对（逐条判 `docs/14` 与 `docs/21`）· 工时 · **审批表**
- **只出图，不改任何产品代码**（`apps/**`、`admin-web/src/**`、`server/**` 一行不动）
