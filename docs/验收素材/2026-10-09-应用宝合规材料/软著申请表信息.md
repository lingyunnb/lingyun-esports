```powershell

$n = 0; foreach ($f in $t) { $n += (Get-Content $f.FullName | Measure-Object -Line).Lines }
"文件数 = $($t.Count)；非空行合计 = $n"
```

```text

```

```powershell

$nt=0; foreach ($f in $ts) { $nt += (Get-Content $f.FullName | Measure-Object -Line).Lines }
"*.vue = $($v.Count) 文件 / $nv 行；*.ts = $($ts.Count) 文件 / $nt 行；小计 = $($nv+$nt) 行"
```

