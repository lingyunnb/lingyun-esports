聊天 UI · v3

v2 的问题不是配色，是工艺：白底配白气泡发平、行高内边距太紧、没有尾角与分组节奏、顶栏与输入栏过于简陋。本版逐项补齐（下表可对照验收）。

v2 → v3 具体改了什么

项v2v3为什么更好看
页面底纯白#EEF1F6 浅灰白气泡浮在灰底上才有层次（微信/Telegram 同做法）
气泡内边距11 × 20 紧14 横向 / 行高 22中文需要 1.55 行高才不挤
尾角无每批首条带小三角指向头像，视觉有"谁在说"的方向感
分组节奏平均 20同人 6 / 换人 18 / 跨时段 24节奏来自"组内紧组间松"，不是处处均匀
头像28 无描边34 + 2px 白描边，与气泡底对齐贴气泡底是聊天布局的通用规范
时间每条都带同批只在末条（10px 灰）减少噪音，重要信息更跳出来
顶栏只有标题返回 + 头像 + 名字 + 在线点 + 更多信息完整才像成品
输入栏文字按钮圆角 18 输入框 + 语音/图片 + 实色圆箭头触感明确，有内容才亮
图片消息灰块裸露白卡内嵌 8 圆角灰块与气泡同一套容器规范
