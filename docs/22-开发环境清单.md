## 五之二、构建必读：Gradle 缓存必须显式指定（本轮实测踩坑）

**症状**：`flutter build apk` 报
`Exception in thread "main" java.net.ConnectException: Connection timed out: connect` → `Gradle threw an error while downloading artifacts from the network`

**根因**：
1. 本机到 `services.gradle.org` 的线路会超时；
2. 默认 `%USERPROFILE%\.gradle\wrapper\dists\gradle-9.3.1-all\<hash>\` 里只有 **0 字节的 `.part` 残留**（一次失败下载留下的），Gradle 认为没下载完，于是每次构建都去联网重下 → 超时；
3. 而 `D:\fish\.gradle-home\wrapper\dists\gradle-9.3.1-all\<hash>\` 里是**完整缓存**（`gradle-9.3.1-all.zip` 224MB + `.ok` 标记）。

**解法**：构建前设 `GRADLE_USER_HOME=D:\fish\.gradle-home`（发布脚本 `release-app.js` 本来就会设，手工构建时容易漏）
```powershell
$env:GRADLE_USER_HOME='D:\fish\.gradle-home'
$env:ANDROID_HOME='D:\Android\sdk'
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
```
**排查口诀**：构建秒失败且报下载超时 → 先看 `%USERPROFILE%\.gradle\wrapper\dists\...\<hash>\` 里是不是只有 `.part`，是则改用 `D:\fish\.gradle-home`。

## 六、电脑重启后的恢复流程（2026-10-04 实测踩坑，照做即可）

> 重启后 Docker 与 pm2 会自动拉起，**但 Cloudflare Quick Tunnel 地址会变**，
> 而 App 内置的是旧地址 → 所有已装 App 立刻失联（表现为"打开就报网络错误"）。必须按序处理：

```powershell
# 1) 确认环境（通常自动恢复）
docker ps                                          # fish-mysql / fish-redis 应 healthy
pm2 list                                           # fish-server / fish-tunnel / fish-admin 应 online
curl.exe -s http://127.0.0.1:3100/api/v1/health    # 期望 ok + db up + redis up

# 2) 抓当前隧道地址（重启后必变！日志含历史地址，必须逐个探测确认"活的"）
$urls = pm2 logs fish-tunnel --lines 400 --nostream 2>&1 |
        Select-String -Pattern 'https://[a-z0-9-]+\.trycloudflare\.com' -AllMatches |
        ForEach-Object { $_.Matches } | ForEach-Object { $_.Value } | Select-Object -Unique
foreach ($u in $urls) { "{0} => {1}" -f $u, (curl.exe -s -m 12 -o NUL -w '%{http_code}' "$u/api/v1/health") }
# 只有一个返回 200；其余为 000（已失效）或 530（隧道已断）

# 3) 更新缓存（发布脚本自动读取本文件，无需改代码）
Set-Content D:\fish\scripts\tmp\.tunnel-url -Value '<活的地址>' -Encoding ascii -NoNewline

# 4) 按新地址重新发布双端（否则存量 App 连不上）
$env:ANDROID_HOME='D:\Android\sdk'; $env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
$env:GRADLE_USER_HOME='D:\fish\.gradle-home'
node scripts/release-boss.js   <下一码> <版本> "服务器地址更新（隧道变更）"
node scripts/release-worker.js <下一码> <版本> "服务器地址更新（隧道变更）"
```

**要点**：
- Quick Tunnel 地址**每次重启都会变**；要固定地址需自备域名 / 命名隧道（见 docs/11）。
- 重新发布必须**递增版本码**（2026-10-04 那次重启后为 boss 37 / worker 29）。
- 2026-10-04 实测新地址：`https://accounting-skins-hepatitis-discretion.trycloudflare.com`（公网 health/分部/找陪玩/榜单/商品全部 200）。

## 七、重装系统后的恢复顺序（照做即可）

1. 装 Node 24 + Flutter（`D:\flutter`）+ Android Studio（含 jbr）
2. `sdkmanager` 装：`platform-tools` `platforms;android-36` `build-tools;36.0.0` `cmake;3.22.1`（NDK 由 Gradle 自动拉）
3. **恢复签名密钥**：把 `data/backups/keys/fish-android-debug.keystore` 复制回 `%USERPROFILE%\.android\debug.keystore`（否则所有存量用户更新失败）
4. 两个工程 `android/local.properties` 写 `sdk.dir=D:\\Android\\sdk`
5. 三端 `flutter pub get`（走国内镜像）；`server` 与 `admin-web` 各 `npm install`
6. 启动 Docker Desktop → `npm run infra:start` → `pm2 resurrect` 或跑 `scripts/recover-after-reboot.ps1`
7. 体检：`npm run infra:status` + `/api/v1/health` + `flutter analyze` 三端
