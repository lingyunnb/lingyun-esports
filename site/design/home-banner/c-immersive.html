零占位（高度 0）—— 但 C 的塌陷代价最大：通栏是满宽的、视觉重量最高的元素，消失后顶部导航与三宫格直接相邻，页面顶部会显得"被削掉一块"。若选 C，建议空态改为保留 0 高度但仍让三宫格上移，并在管理端把"未配置"做成一条警告（不能让首页看起来像坏了）。

规格与理由（每个数字都要能说出理由 —— docs/21 第六节第 4 条）

项取值理由
槽位位置紧贴顶部导航下方（在三宫格之上，ListView 第 2 个 child）C 的定位是"活动位"：靠满宽 + 无圆角 + 贴顶表达"我在页面最外层"。代价是把「投诉/打赏/退款」下移一行（约 44pt），并让"选分部→下单"这条业务主路径退到活动位之后
宽度390 满宽，左右留白 0与"通栏"语义一致；不通栏就不叫 C 了
卡片尺寸390 × 156（比例 2.5:1）通栏已经靠宽度拿到视觉重量，高度必须收：156 让三宫格仍完整落在首屏
圆角0（无圆角）顶部第一屏唯一无圆角元素 = 版面的"顶盖"，这是有意的层级手段
指示器图内底部居中短条底部被三宫格占用的是下边界，指示器只能内嵌；居中是因为满宽时左右两端没有参照点
切换动画位移 + 吸附，320ms easeOutCubic同 A
自动播放建议必开 5s（若选 C）C 是"活动位"，用户不会主动去滑它；不开自动播放，绝大多数用户只会看到第 1 张
循环是同 A
单张时不显示指示器同 A
空态零占位，但需管理端警示见上
与浮标/底栏关系无冲突槽位在最顶部；浮标与凸起底栏在下半部。C 把内容整体下推 156pt，「选择分部」标题落在 y≈428，五张分部卡会有一段落到首屏之外（可滚动，不算冲突，但要如实说明）

顺序决策（与既有元素的关系）

顶部导航 → 宣传图（C，紧贴其下） → 投诉/打赏/退款 → 欢迎语行 → 选择分部 → 祁连山官方
  • 与「投诉/打赏/退款」三宫格：C 把通栏放在三宫格之前，三宫格下移约 44pt。代价是三个订单操作入口退到活动位之后。
  • 与"欢迎语行"：C 在欢迎语行之前（欢迎语行被推到三宫格之后）。欢迎语行是品牌人格（董事长欢迎语），位置靠后不影响其功能。
  • 与「选择分部」：所有方案宣传图都在「选择分部」之前。理由：宣传图是转化前的活动耳语（不参与下单主路径，不产生分支），而「选择分部」是主路径的第 0 步。活动位放在主路径之前，是"看一眼活动 → 进入正事"的自然阅读顺序；放在分部卡之后就变成"下完单才看到活动"。
  • 不与右下「立即下单」浮标打架：浮标固定在 right:16 / bottom:96，宣传图在最上方，纵向完全不重叠；宣传图不做横向全屏手势区（滑动只在自己的框内），不会抢浮标的点击。
  • 不与底部凸起「祁小山」打架：凸起位在底栏中间（bottom:30 + 54pt 圆 + 上方 26pt 标签），属于最底部 60pt 区域，与顶部宣传图相距 > 600pt；宣传图的自动播放也不覆盖底栏（不是全屏浮层）。

交互规格（给实现用）

  • 滑动：横向整页吸附（Flutter PageView），松手吸附最近整页；过渡 300–320ms easeOutCubic。
  • 循环：首尾相接（末页右滑回首张）。实现建议：页数 > 1 时用 itemCount = n + 2 的哨兵页，或直接不加循环（3 张的活动位循环不是必须，需负责人定）。
  • 自动播放：默认关闭；管理端可开（间隔 5000ms）。用户手指按下即暂停、松手 8s 后恢复（这是行业通行做法）。
  • 点击：link_type = none 时整卡不可点（不给"假可点"反馈）；其余类型整卡可点 + 按下的轻微透明度反馈（opacity .92，不做缩放动画）。
  • 加载态：358×163 的浅灰 #E7EEFE 圆角块，不闪、不做 shimmer（docs/21：不做炫技动效）。
  • 错误态：与页面其它接口一致 —— 宣传图拉取失败静默不显示（首页不该因为一个活动位而出现错误卡）。
