# 祁连山电竞 · 品牌视觉升级方案（第一阶段 · 待审批）

> 依据：`docs/29-竞品视觉研究.md`（竞品）+ `docs/28-品牌视觉现状盘点.md`（我方现状，853 行审计）

---

## 〇、一句话结论

我方界面**不是"没设计"，而是"没有品牌层"**：色彩/字体/图标/组件**四层都缺统一约束**，
所以每个页面都在**各自手搓**（302 处硬编码色值、29 种字号、22 种图标尺寸、23 种圆角、296 个手搓白卡面）。
竞品的经验是：**辨识度来自"一个非常规主色 + 一套克制的辅助图形 + 内容本身（游戏 Logo/商品图）"**，而不是堆装饰。

**升级的杠杆点只有一个**：**先把散落的硬编码收敛回 token（一次性），之后"换品牌"＝改几个 token 值。**
不先做这一步，任何配色方案都会变成几百处改动、且下次再也改不动。

## 一、竞品给我的三条硬结论

| # | 结论 | 证据 |

## 三、决策项 1：品牌主色（**这是"看起来像模板"的头号原因**）

现状 `#2563EB` 是 **Tailwind 默认蓝** —— 全世界用得最多的蓝之一，**天生没有品牌感**。

### 三套完整配色方向（请选一套）

#### 方向 1｜墨蓝 × 青瓷（**推荐**）
气质：**高端服务业**（私人银行 / 精品酒店）—— 稳重、克制、专业，且**不靠金**。
| 角色 | 色值 | 用途 |
|---|---|---|
| 品牌锚 | `#0F2440` 墨蓝 | 品牌区 / 深色块 / HeroCard 底 |
| **主交互** | `#1D5FA8` | 按钮 / 选中 / 链接（白字对比 ≥5:1） |
| **强调** | `#0E7C7B` 青瓷 | 次级强调 / 成功 / 选中描边 |
| 价格·等级 | `#B4732A` 低饱和琥珀 | 金额 / 等级（**去掉现在的亮橙金**） |
| 页底 / 卡面 / 发丝线 | `#F4F6F9` / `#FFFFFF` / `#E3E8EF` | |
| 正文 / 次要 / 弱化 | `#14202E` / `#4A5A6E` / `#8A99AB` | |

#### 方向 2｜石墨 × 朱砂
气质：**极简黑白灰 + 中式强调**，最"高级"也最冷；主按钮用近黑，风险是**不够亲和**。
品牌锚 `#1C1C1E` · 主交互 `#2C2C30` · 强调 `#B23A2E` 低饱和朱砂 · 价格 `#A8741F`

#### 方向 3｜黛蓝 × 哑金
气质：保留蓝系但换掉通用蓝；风险是**最接近现状**，改动感知度最低。
品牌锚 `#0B2A3D` 深黛 · 主交互 `#146C94` 深青蓝 · 强调 `#C9A227` 哑金

### 三套共有的规则（比选哪套更重要）
1. **价格/等级色全站只用一个**（低饱和琥珀系），**不再出现第二个金**
2. **渐变面积压到 ≈0**（`docs/21` 已禁"渐变做主视觉"）—— 品牌区用**实色深块**
3. **每套必须过对比度实测**：正文 ≥4.5:1、大字 ≥3:1；把 `admin-web/src/styles/tokens.css:372-392` 那张**逐值对比度速查表的方法搬到 Flutter 侧**（审计认定这是全仓最有价值的资产之一）
4. **色不多、但用得狠**：深色块只出现在**品牌区 + 主推商品**两处，其余保持大量留白

## 四、决策项 2：Logo 与「山」的去留

### 现状（审计实测）
- App 图标：**结构齐全但偏弱** —— 源图 1254²，5 层细节（山+雪帽+手柄+弧线+星芒）**占画面 65–70%**，硬缩到 48dp **必然糊**
- **iOS 36 个图标全是 Flutter 默认蓝 F 占位图**（从未替换）
- **启动图 XML 被 `drawable-v21/` 覆盖 → 真机永不生效**（实际露脸的是 Dart 闪屏里画的山标）
- **App 内从未用过山位图**；商品卡/个人中心都不适合用
- **自绘山标有两枚形态不同源**却同 App 共存（双峰 `AppMountainMark` + 单峰「祁」字 `AppQishanMark`）
- 「山」意象全仓 **23 处**；`docs/14:69` 明文写「以祁连山雪山为核心意象」（**与负责人本次要求冲突，需明确废止或修订**）

### 三个方案（请选一个）

| 方案 | 做法 | 优 | 劣 |
|---|---|---|---|
| **甲｜字标为主（推荐）** | 「**祁**」字标提纯为**一枚几何字标**（去掉山形）做**主标识**；写实雪山**降级为辅助纹理**（大尺寸 + 低透明度，只做背景） | 48dp 下清晰；保留品牌名记忆点；符合"名字有山≠必须画山" | 需同步改锁定像素的出图测试（`mountain_mark_layer_test.dart` 等） |
| 乙｜山形抽象化 | 把写实雪山提纯为**1–2 个几何块**的山形符号做主标 | 保留"山"意象 | **极易与大量"山峰 logo"撞脸**，反而降低辨识度 |
| 丙｜双轨 | 主标用字标；山形符号**只用于会员等级徽章 + 辅助纹理** | 山的意象有去处 | 两套符号仍并存，需严格约束使用场景 |

**推荐甲** + 采纳丙的一部分（山形只作纹理）。**无论选哪个，都必须处理**：iOS 默认图标、启动图失效、两枚山标同源问题。

## 五、决策项 3：品牌辅助图形（**从 0 建立**）

现状**完全没有**（`Image.asset` 全仓 0 次）。建议一套**克制、可复用、非廉价电竞**的几何系统：

| 元素 | 做法 | 为什么不用常见的那些 |
|---|---|---|
| **主符号：斜切角（chamfer）** | 卡片 / 标签 / 按钮的角部做 **45° 小切角**（1–2 处），取代"全大圆角" | 工业感/精密感，**天然区别于所有大圆角模板**；不是闪电/霓虹/发光 |
| **背景纹理：等距细网格** | 1px 网格，透明度 **3–5%**，**只用于品牌区与空态** | 克制的"工程感"；替代装饰插画 |
| **分隔语言：标尺线** | 1px 发丝线 + 端点小方块，用于区块分隔 | 比纯线更有品牌味，成本极低 |
| **禁用** | 闪电 / 密集霓虹 / 发光堆砌 / 粒子 / 装饰插画 / 星空 | 负责人已明确禁止的廉价电竞风 |

> ⚠️ **官网仍在跑旧紫蓝装饰**（`#5B6CFF` / `#9B6EFF` / `#E8C27A`），**正面违反 `docs/21`** → 纳入本次清理。

## 六、四层体系的收敛规范（具体数字）

### 1. 字体阶梯（29 种字号 → 7 级）
| 级 | 字号 | 用途 | 字重 |
|---|---|---|---|
| Display | **22** | 页头大标题 | 800 |
| Title | **18** | 区块/卡片标题 | 700 |
| Subtitle | **15** | 列表主文案 | 600 |
| Body | **13** | 正文 | 400 |
| Caption | **12** | 辅助说明 | 400 |
| Micro | **11** | 标签/时间（**规范原缺，实际用得最多**） | 400 / 600 |
| Numeric | 金额数字 | **等宽数字（tabular）**，按上下文取 15/18/22 | 700 |

**顺带必修**：`worker-app` 声明了 MiSans 但 `pubspec` **无 fonts、无 assets → 静默回落系统字体**（自测注释自认）→ **字体不一致**。

### 2. 图标体系（5 套 → 1 套）
- **统一为 `AppIcon` 单套**；把 **253 处直接 `Icons.*`（119 个绕过名）** 分批替换（先替换**出现频次最高的 30 个**，覆盖大部分）
- **尺寸从 22 种值收敛为 4 档**：**16 / 20 / 24 / 28**（现在 13/15/16/17/18 五档共 100 处，肉眼不可辨）
- **选中态统一一种表达**：线性 → 主色 + 加粗（不再 3 套并行）
- `admin-web` 7 条手写 SVG 归入同源图标集

### 3. 组件体系（补件 + 分级）
**卡片必须分 3 档**（这是打破"全白圆角矩形"的核心手段）：
| 档 | 形态 | 用途 |
|---|---|---|
| **HeroCard** | **深色实色块 + 斜切角 + 辅助纹理** | 品牌区 / 主推商品（每屏最多 1 个） |
| **ContentCard** | 白卡 + 统一圆角（**取规范档位，删掉越档的 16**） | 常规内容 |
| **ListCard** | 无圆角分组 + 发丝线 | 列表/设置项 |

**要补的组件**：`AppListItem`（列表行规范）· `AppStatusTag`（**统一现在 4 套私有状态色板**，含 `level_style.dart` 30 处硬编码）· `AppBadge`（角标/计数）· `AppSegmented`（推广，现仅 6 处）· `FishSkeleton`（抽公共，现 12 次全在自己文件内）· `AppEmpty` 推广到管理端（24 表仅 3 个用空态）

### 4. 动效体系（25 种时长 → 3 档）
- **时长**：`fast 120ms` / `base 200ms` / `slow 320ms`（删掉 3 套互相冲突的常量）
- **曲线 2 条**：`standard`（进入/移动）· `emphasized`（页面切换）—— 现在**两者同值**，需真正区分
- **`easeOutBack` 回弹 6 处**：只保留在"成功反馈"，其余改 `standard`
- **禁止**为了炫酷加复杂动效（`Hero` 现仅 1 处真实使用、`AnimatedList` 0 处 —— **保持克制**）

| # | 区域 | 现状问题 | 改造方向 |

| 6 | **首次理解** | —— | 首屏让用户**看懂"提供什么服务、怎么下单"** |
