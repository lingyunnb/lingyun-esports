## 三、推荐稿与理由

**推荐：方案 C（前三名强化行）** → 细化稿见 `site/design/leaderboard-redesign/recommended.html` / `recommended.png`。

1. **逐条压掉 5 个缺陷**，且不引入新的设计决定：渐变横幅删除（缺陷 1 / 4）、榜名 3 次 → 1 次（缺陷 2）、
   周期与分部拆两排（缺陷 3）、前三行加高 + 实色徽章 + 金额分层（缺陷 5）。
2. **比 A 多解决"榜首感"**：A 的前三名与第 10 名仍同高同字号，只差徽章色 —— 负责人点出的"层级扁平"只解决一半。
3. **比 B 的风险低**：B 把第 1 名拆成卡片，榜单被切成"卡 + 列表"两种形态，且要额外决定"卡片投影算不算违反
   docs/21「阴影只给弹层」"；C 仍在**同一条列表**里，0 新组件、0 新卡片、0 阴影争议。
4. **与「我的」页方案 B 视觉同族**：白底页头 + 发丝线 + 冷灰蓝底 + 琥珀金只用于金额与榜首
   （对照 `site/design/profile-redesign/B.html`），同一 App 内一致。
5. **最小可回退**：改的是同一个文件的 9 处，删掉任何一处都能退回上一形态，**没有数据结构与接口牵连**。

### 3.4 推荐稿的深色版（**需独立一轮才能上线**）

- **老板端当前没有深色 token，也没有主题开关**：`apps/packages/core/lib/src/theme/app_colors.dart` 只有一套浅色真值；
  `ThemeController` 的两套主题是「初始 / 液态玻璃」（`docs/14` 「主题系统」一节），都**不是深色档**；
  docs/14 里成文的深色列只属于**管理端外壳**（`html[data-theme]`，`docs/14`「管理端外壳」）。
- 本稿深色版取色**全部来自 docs/14 深色列**（三端同色系）：底 `#0B1220` · 表面 `#111C2E` · 发丝线 `#1E2C42` ·
  行间线 `#182539` · 正文 `#E8EEF7` · 次级 `#9DB0C8` · 三级 `#8CA3BE` · 主色（文字态提亮）`#7FB0FF` · 琥珀金 `#F0A63C`。
- 深色下的两处口径：① 选中胶囊由浅底改 `#16263F` + 提亮主色 `#7FB0FF`（`#2563EB` 在深底上当文字用对比度不足）；
  ② 金额提亮为 `#F0A63C`。徽章实色（金/灰/橙 + 白字）在深色下不变。
- **为什么只做预览**：要真上线深色，需先在 core 新增一整套深色 token（现在没有 `dark*` 系列）→ 再给
  `ThemeController` 加第三档主题 → 再**逐页**回归。**这一步要独立一轮**，不能夹在本次排行榜改动里做。
