统一空态组件

建议 图标 + 一句话 + 可选操作按钮 AdminEmpty
老板打手状态
还没有任何绑定记录 老板在老板端「我的」里绑定打手账号后，这里会出现一条记录：老板、打手、绑定时间与上限占用。 刷新
① 图标：38px 圆形 + 发丝描边（不是彩色实心块） ② 一句话：说结论 ③ 说明：给下一步（可省略） ④ 按钮：可选，且必须是真能解决问题的那个
✓ 为什么必须有图标：空态是一块大白卡，纯文字会让人以为"页面没加载完"。 一个灰调线性图标就能把"这里是空的、但功能正常"说清楚 —— 且它是结构而非装饰（docs/21 第六条自检）。
API 组件接口建议 components/AdminEmpty.vue
// admin-web/src/components/AdminEmpty.vue interface Props { /** ① 图标：复用各页已有的线性图标体系（不引第三方图标库） */ icon?: 'inbox' | 'search' | 'wallet' | 'user' | 'chat' | 'chart'; /** ② 一句话结论（必填）：说清"现在是什么状态" */ title: string; /** ③ 补充说明（可选）：给"下一步该做什么" */ desc?: string; /** ④ 操作按钮（可选）：真能解决问题的那一个 */ actionText?: string; /** 紧凑模式：表格行数少/抽屉内嵌时用（padding 减半） */ compact?: boolean; } emit: { action: [] } // 父组件决定点了做什么
// 用法：表格里一行接上（替代 Naive 默认「暂无数据」） <n-data-table :columns="columns" :data="rows"> <template #empty> <AdminEmpty icon="search" title="没有符合筛选条件的工单" desc="换个状态或清空关键词试试。" action-text="重置筛选" @action="reset" /> </template> </n-data-table>

必须区分两种"空"（这是统一的前提）

状态标题（结论）说明与动作
筛不出来
有筛选条件 / 有关键词		 没有符合筛选条件的<对象> 说明：提示可放宽条件；动作 = 重置筛选（IdentityBindingsView 的既有做法，推广到全部页面）。
还没有记录
无任何筛选条件		 还没有<对象> 说明：讲清"这条记录是怎么产生的"（如"老板绑定打手后会出现一条"）；动作可选（有明确去处才给按钮）。
无权限
不是空，是拿不到		 需要 admin:xxx 权限点 不要用空态组件：权限缺失是另一类状态，必须明说缺哪个权限点（AuditView 已按这个口径修过，F1）。

逐项口径

项内容
现状24 个有表格的页面里，21 个用 Naive 默认「暂无数据」（四个字、无图标、无动作）；3 个写了 #empty（IdentityBindingsView / RechargeView / WithdrawView），其中只有 IdentityBindingsView 区分了"筛不出来"与"还没有记录"并给了按钮。工作台的 .nav-empty / .stat-empty 又是另一种（虚线框 + 一行字）。
建议① 新增 admin-web/src/components/AdminEmpty.vue：图标（38px 圆形线性）+ 一句话结论（必填）+ 可选说明 + 可选操作按钮，props 见上；
② 逐页把 #empty 插槽接上它（先做 6 个高频页：OrdersView / UsersView / WorkersView / WalletsView / AppealsView / ComplaintsView），其余页面后续批量替换；
③ 统一按上表区分三种状态，权限缺失不用这个组件；
④ 顺手把工作台的 .nav-empty / .stat-empty 也换成它（compact 模式）。
影响面不需要动服务端。纯展示层；不动接口、不动数据结构、不动分页与筛选逻辑。
改动面广（21 个页面）但风险低 —— 每个空态只在 rows.length === 0 时渲染，不影响有数据的路径。建议分两批：先 6 个高频页，验证后再铺开。
红线docs/14：否。§「页面设计检查清单」第 5 条"状态是否容易理解"、第 6 条"页面是否拥挤/过于空"，本项正是照这两条做。
docs/21：否，且是正向合规。§五「交互层」明文要求"必须设计空态 / 加载态 / 错误态（只有 happy path = 真实使用时会像坏了）"、"空态给下一步动作"—— 本项就是补上这条。
图标为灰调线性（--color-text-tertiary + 发丝描边圆底）：不是彩色实心块、不是 emoji、不是装饰插画。
工时1 天（组件 0.5 天 + 6 个高频页接入 0.5 天；其余 15 页约 0.5 天可另批）。
