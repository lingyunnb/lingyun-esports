设计语言拆解（关键点）

① 主色紫 #7C4DFF + 渐变紫粉 #A855F7：选中态、悬浮＋、榜单横幅、活动 Banner
② 价格金色 #F0B429：永远最大最亮，与紫色形成双强调
③ 角标是层级核心：卡片左上角彩标（服务天花板/开业福利/自营）
④ 状态标签体系：空闲（绿）/忙碌（橙）/单考（黄）/双考（粉）/明星打手（金）
⑤ 胶囊两段制：一级=文字标签带下划线，二级=胶囊（选中紫底白字）
⑥ 下单入口无处不在：底部中间凸起＋、右下「自助下单」浮标

E3 排行榜

E4 东友圈

视频 / 帖子 / 热榜 三标签；筛选胶囊（热门/最新/关注/吃瓜）→ 活动 Banner → 置顶 → 帖子流（等级徽章 + 话题 + 三图 + 互动数）。

E5 消息

聊天（红点）/ 好友 / 群组 + 一键已读 + 搜索ID/昵称 + 彩色圆形会话图标（活动公告/官方公告/好友/订单群）+ 未读气泡。

E6 我的

资料头（大头像/ID/单身中/个人主页）→ 三数据 → 我的权益深色卡（钻石·猫粮 + 尊享卡/优惠券）→ 三个权益入口 → 等级进度卡 → 更多服务。

与现有功能的映射（重要）

照抄界面 ≠ 丢掉功能
