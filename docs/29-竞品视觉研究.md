## 二、棠舟电竞（真实截图 · 可信度高）

来源：`www.cisis.com.cn/file/img/08142859iyav6w1fai4b.png`（**全屏真实截图**）

### 观察到的事实
| 元素 | 做法 |
|---|---|
| **顶部品牌区** | 「棠舟陪玩」居中标题；**深酒红/勃艮第底色 + 极淡的暗纹**（不是纯色，也不是渐变） |
| **搜索** | 胶囊输入框（深色半透明）+ **品红圆形搜索钮** |
| **游戏分类** | **圆角方形游戏 Logo 磁贴**（5 个：三角洲行动/英雄联盟/绝地求生/无畏契约/声优语聊）+ 下方中文名 —— **用游戏自己的 Logo 建立识别度**，不用通用图标 |
| **筛选** | 胶囊 chip：全部（选中＝**实色品红填充**）/ 金棠陪玩 / 银舟陪玩 / 新人推荐（未选中＝深底 + 细描边） |
| **陪玩卡** | **两列网格**；卡片＝**大幅人物图（占卡片 55%）**→ 名字（白，粗）→「陪玩人员」小标签 → **数据行（⭐评分 / 🎮已接单）** → **推荐数** → **「预约」按钮（品红实色，卡片内唯一按钮）** |
| **氛围** | 深色底 + 高饱和品红点缀；**人物图是视觉主角**，文字克制 |

### 宣传图里另外看到的
- 「专业陪练 / 职业选手，游戏带飞」大标题 + **粉紫渐变 + 动漫吉祥物**主视觉
- 卡片形态与真实截图一致（头像/名字/段位描述/空闲徽章/已接单/评分）

### 可借鉴的**设计理念**（不抄资产）
1. **强品牌色 + 强对比**：深底 + 单一高饱和强调色 —— 辨识度来自「**敢用一个非常规主色**」，而不是中性蓝
2. **游戏用官方 Logo 磁贴**做分类 —— 识别度由「内容本身」承担，比自绘通用图标更专业
3. **卡片有"视觉主角"**：人物图占大头，其余信息围绕它排 —— 不是所有卡都长一样
4. **每张卡只有一个实色行动按钮**，行动点清晰不打架
5. **筛选 chip 的选中态用实色填充**，未选中用细描边 —— 状态一眼可辨（且**不只靠颜色**：形状/填充/字重都在变）

## 五、结论：可借鉴的 6 条「理念」（**不是资产**）

1. **辨识度来自"敢用一个非常规主色"** —— 两家都用了强性格色（棠舟＝酒红+品红；东东＝紫系），**没有一家用中性蓝**。我方当前是 `#2563EB` 通用蓝 → **这是"看起来像模板"的头号原因**
2. **让"内容本身"承担识别度** —— 棠舟用**游戏官方 Logo 磁贴**；比自绘通用图标更专业，也更省设计成本
3. **卡片必须有"视觉主角"** —— 人物图/商品图占大头，其余信息围绕它组织；**不能让所有卡都是同尺寸的白圆角矩形**
4. **状态不只靠颜色** —— 选中 chip 同时变填充、描边、字重；徽章有形状差异
5. **每张卡只有一个实色行动按钮** —— 行动点唯一、清晰
6. **底部导航/分类用真实图标而非 emoji 或通用符号**

## 六、**明确不该抄的**（法律与品味双重原因）

- **不抄**：棠舟的动漫吉祥物、粉紫渐变主视觉、任何一个游戏 Logo 之外的专属图案
- **不抄**：东东的星空粒子语聊房视觉（且我方无此功能）
- **不抄**：两家的 Logo、专属文案、独特页面结构
- **不采用**：廉价电竞风（夸张闪电 / 密集霓虹 / 发光堆砌 / 黑红撞色）—— 负责人已明确禁止
