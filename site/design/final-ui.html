1 首页

分部渐变卡（3 个：和平精英·手游通栏、三角洲·手游/端游）→ 祁连山官方（2 张，带渐变封面 + 官方标）→ 保障说明。无服务分类胶囊、无多档俱乐部标签。

2 找陪玩

渐变圆头像 + 名字 + 介绍（介绍由管理端填写）；行高随介绍长短自适应；顶部分部胶囊；和平精英下不出现端游。

3 排行榜

子榜胶囊 + 渐变横幅 + 分部/日周筛选 + 名次 + 头像 + 名字 + 接单金额（每行不写分部、不带标签）+ 吸底我的排名。

4 玩家圈

筛选胶囊 + 活动条 + 帖子卡（渐变圆头像 / 具体内容 / 话题 / 图片 / 互动）。

5 消息

三类：好友私聊 / 客服 / 打手；卡片化会话 + 角色标签；系统通知与公告归「公告」；订单群进订单详情。

6 我的

渐变圆头像 + 名字/ID/等级/分部 → 积分卡 → 订单三状态 → 常用四项 → 会员成长进度。
