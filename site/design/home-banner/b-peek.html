规格与理由（每个数字都要能说出理由 —— docs/21 第六节第 4 条）

项取值理由
槽位位置同 A（欢迎语行之下、「选择分部」之上）理由同 A；B 与 A 只在"框体形态"上不同，信息架构一致 → 两种方案可互为降级
卡片宽度335pt = 86% × 390，居中，左右各 27.5露边量 = 390 − 27.5 − 335 − 10(gap) = 17.5pt，约等于一个图标的宽度：看得见"还有一张"，但不会误触
卡片尺寸335 × 188（比例 16:9）露边布局通常用于"素材需要更高"的场景（人物图/信息图）；16:9 是这个场景的通用比例，也给素材方更好排版空间
圆角10露边时圆角过大会显得软塌、且两卡相邻处会出现"圆角对圆角"的锯齿感；10 与信息卡同档更稳
指示器卡片下方居中圆点 5px关键理由：露边布局里卡片会左右位移，图内指示器会跟着卡片滑动而"抖动/错位"；移出卡片后指示器是页面元素，位置恒定
切换动画吸附，300ms easeOutCubic；相邻卡随位移微缩放 1.0→0.97微缩放让"当前页/下一张"的层级一眼可辨，这是露边布局的标准做法（同 iOS App Store / 小红书）
自动播放默认关闭，管理端可开（5s）同 A
循环是同 A
单张时退化居中单卡，无露边、无指示器见上
空态整槽不渲染（高度 0）见上
与浮标/底栏关系无冲突同 A；B 更高（188），「选择分部」标题被推到 y≈400 附近，仍在首屏内

顺序决策（与既有元素的关系）

顶部导航 → 投诉/打赏/退款 → 欢迎语行 → 宣传图（B） → 选择分部 → 祁连山官方
  • 与「投诉/打赏/退款」三宫格：宣传图始终在三宫格之后。三宫格是"订单相关操作入口"（投诉/打赏/退款），属于工具行；工具行贴顶是这类 App 的共同习惯，也是 docs/21"顺序按业务需要"的直接体现 —— 用户找退款时不该先划过一张活动图。
  • 与"欢迎语行"：宣传图在欢迎语行之后。欢迎语行只有 2 行 11.5pt 小字、高约 40pt，承担"这是官方自营"的心理铺垫；把它压在宣传图上方等于用一张活动图打断"导航 → 操作入口 → 品牌问候"的三拍节奏。
  • 与「选择分部」：所有方案宣传图都在「选择分部」之前。理由：宣传图是转化前的活动耳语（不参与下单主路径，不产生分支），而「选择分部」是主路径的第 0 步。活动位放在主路径之前，是"看一眼活动 → 进入正事"的自然阅读顺序；放在分部卡之后就变成"下完单才看到活动"。
  • 不与右下「立即下单」浮标打架：浮标固定在 right:16 / bottom:96，宣传图在最上方，纵向完全不重叠；宣传图不做横向全屏手势区（滑动只在自己的框内），不会抢浮标的点击。
  • 不与底部凸起「祁小山」打架：凸起位在底栏中间（bottom:30 + 54pt 圆 + 上方 26pt 标签），属于最底部 60pt 区域，与顶部宣传图相距 > 600pt；宣传图的自动播放也不覆盖底栏（不是全屏浮层）。

交互规格（给实现用）

  • 滑动：横向整页吸附（Flutter PageView + viewportFraction: .86 + padEnds: true），松手吸附最近整页；过渡 300–320ms easeOutCubic。
  • 循环：首尾相接（末页右滑回首张）。实现建议：页数 > 1 时用 itemCount = n + 2 的哨兵页，或直接不加循环（3 张的活动位循环不是必须，需负责人定）。
  • 自动播放：默认关闭；管理端可开（间隔 5000ms）。用户手指按下即暂停、松手 8s 后恢复（这是行业通行做法）。
  • 点击：link_type = none 时整卡不可点（不给"假可点"反馈）；其余类型整卡可点 + 按下的轻微透明度反馈（opacity .92，不做缩放动画）。
  • 加载态：358×163 的浅灰 #E7EEFE 圆角块，不闪、不做 shimmer（docs/21：不做炫技动效）。
  • 错误态：与页面其它接口一致 —— 宣传图拉取失败静默不显示（首页不该因为一个活动位而出现错误卡）。
