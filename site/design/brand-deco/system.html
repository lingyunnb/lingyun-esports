统一性内核：一套装饰 = 一条 45° 线 + 一张 4dp 网格

「一眼认出是同一套」不靠多画元素，靠三个重复量：① 全部切口都是 45° 直线（没有圆角切口、没有弧形、没有三角拼贴）； ② 全部线宽只有 2 档（1dp 发丝 / 2dp 品牌）；③ 全部尺寸只落 4dp 网格（切口 6×6 与 8×8、端点 3×3、标尺到内容 8dp、线到内容 12dp、区块间 20dp）。 把这三条对所有装饰位重复一遍，跨页面就自动是同一套 —— 不需要"每页配一个彩色小标签"去提示"我们是一个品牌"。

重复量 ①｜角度所有斜切角 = 45°。状态标签 / 分区标签 / 筛选胶囊选中 / 小角标 / 卡片角 / 徽章角 —— 同一把刀口，只是尺寸分两级。
重复量 ②｜线宽只两档：1dp（#CDD6E2 描边 · #E3E8EF 发丝）与 2dp（#1D5FA8 品牌）。不出现 0.5dp / 1.5dp / 3dp 的中间值。
重复量 ③｜落格装饰的每个尺寸与间距都是 4dp 倍数：切口 6/8、端点 3（3×3 为对齐像素取 3）、标尺到内容 8、线到内容 12、区块间 20、页边 16。

元素少的时候靠什么撑住品牌识别度？（本题核心） 陪玩/打手的展示字段被收窄到「头像 + 名字 + 介绍 + 接单次数 + 好评率」——状态胶囊、评分、价格、徽章一律不画，能挂装饰的地方确实变少了。 负责人 2026-10-15 放宽了手段：「品牌化装饰我们可以用颜色、自创的、普通的那些」—— 所以识别度不再只押在版式上，而是押在三个量被同时重复上：45° 刀口 × 4dp 网格 × 三档尺度的色彩用量（三档 = 极浅底 / 实色描边 / 极小面积品牌锚）。

① 刀口重复页面元素越少，"唯一的形状信号"就越显眼 —— 全站只剩一种切口形状（45°），它会成为用户脑中"这个 App"的锚点，而不是被十几种装饰冲淡。
② 尺度的重复颜色不当"填色板"，而当"三档音量"：极浅底（#E8EEF7/#E3F0EF/#F7EDE0/#F4F6F9）打底 · 实色/描边（#1D5FA8/#0E7C7B）定位 · 极小面积品牌锚（#0F2440）落徽。任何一个元素用色，都能说出它属于哪一档。
③ 分工与节奏重复内容行 = 发丝线（无端点），区块 = 标尺线（3×3 端点）；组内紧（8/12）组间松（20/24）四页一致。字段少时，字重对比（800/700/600/400）与留白承担了原本靠彩色标签承担的层级。

反过来说：如果"刀口 / 三档色彩 / 线的分工"这三件事里有两件没做到，页面就会同时"元素少"且"没有品牌"。 所以第 ⑤ 节的标签扩展与第 ⑦ 节的配色规则必须做扎实 —— 它们共同承担了元素变少后的识别度。

为什么在卡片语言里也留这个位

等级标识会同时出现在两处：列表行（陪玩/打手列表）与身份卡（打手信息页顶卡）。两处都用同一份几何：高 20、最长 72、与名字间距 8dp、与名字同一行且垂直居中。

本轮不画形态（负责人尚未给名称）。第 ⑤ 节的标签规则已经把这个尺寸档的形态定死：高 20 → 右上 6×6 斜切角、字号 11、字重 700，所以名称一到就能直接落，不需要重新排版。

唯一金的第二个合法位置

铁律「全站唯一金 #B4732A 只给价格与等级」里的等级就是这里。也就是说：L-SLOT 是唯一不与价格冲突的用金位置；除它之外出现金即违规。

自检问题本套装饰的答案
1 把内容换成同行的，还成立吗？不成立：切口尺寸由"元素高度 ÷ 4"决定、标尺线端点方块只在品牌色+描边灰两色间取值、金币唯一性绑定业务语义（钱/等级）—— 换内容即不自洽。
2 用了模型反射式默认吗？没有：渐变 0 处、阴影 0 处（卡片）、圆角集合固定 5 档、无卡片阵、无居中对称。
3 把装饰全删掉，还剩什么？剩下完整结构：页头/区块/列表/卡片/金额/状态全部独立成立 —— 装饰只做"加快识别"，不承担层级。
4 每个颜色/圆角/间距能说出理由吗？能：每个装饰元素都配了"它解决什么问题 / 去掉会怎样"（见上 6 节每格规则句）。
5 假数据具体、长短不一、有业务味吗？是：¥115.52 / ¥4,286.50 / 2,847 单 / 9:00-次日 2:00 / 商品名取真实目录口径。
6 空态/加载/错误态都设计了吗？是：第 ⑥ 节三态齐备，且空态给下一步动作、骨架与真内容同形不跳版。
⑦ 配色使用规则负责人 2026-10-15：「品牌化装饰我们可以用颜色 用自创加普通的那些」配色使用规则表
先定一个前提：白底为主 ≠ 不能大胆用色。读法是「底色仍以白为主（页底 #F4F6F9、卡面 #FFFFFF），装饰元素可以大胆用色」—— 不是"可以铺大块深色底"。 这条读法同时解释了 docs/32 铁律 1「渐变面积 ≈ 0 → 品牌区一律用实色深块」与 docs/39「取消一切整块深色/蓝色大块」：两处说的是底色，不是装饰元素的用色。 所以本节把颜色当成三档音量而不是填色板：只有刻度、没有色彩会显得寡淡；只有色彩、没有刻度就会退回"模板感"。三档同时在场，才是"一眼认出"。

配色一致性怎么验

"通用做法"的三条准入

① 必须能说出解决什么问题；② 必须落 4dp 网格；③ 必须能在不改变结构的前提下删掉。三条缺一 → 不入系统（回到本表标"不用"）。

三档色彩用量的自检口径

脚本实测四页：品牌色实色面积 ≤ 3%、金只做文字（金色块 = 0 处）、墨蓝每屏 ≤ 1 处、全文档渐变面积 = 0（软渐变）、卡片阴影 = 0 处。任一条不成立即为"用色过头"。
