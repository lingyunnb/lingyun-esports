## 六、原始数据

| 文件 | 说明 |
|---|---|
| `data/temp/dd-res.txt` (3.57MB) | `aapt2 dump resources` 原始转储 |
| `data/temp/dd-spec/dongdong-design-spec.md` | 解析后的完整报告（572 色 / 910 尺寸 全量） |
| `scripts/tools/parse-aapt-resources.js` | 解析器（可复跑） |
| `scripts/tools/apk-design-spec.py` | APK 通用分析器（技术栈识别 + 清单 + 结构） |

**复跑命令**
```bash
# 1) 转储资源（cmd 原生重定向，避免 PowerShell 写成 UTF-16）
cmd /c "D:\Android\sdk\build-tools\36.0.0\aapt2.exe dump resources <apk> > dd-res.txt"
# 2) 解析
node scripts/tools/parse-aapt-resources.js dd-res.txt --out <输出目录>
```

> ⚠️ **踩坑留痕**：PowerShell 的 `>` 重定向会把 aapt2 的 UTF-8 输出写成 **UTF-16LE**（正则全失效）；
> 且 JS 的 `.` **不匹配 `\r`**，按 `\n` 切行会留 `\r` 导致 `(.+)$` 永远失败 → 必须按 `/\r?\n/` 切。两处都已修进工具里。
