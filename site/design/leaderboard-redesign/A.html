方案 A · 去横幅 · 信息归位

排行榜重设计 · 方案 A：删掉渐变横幅，把信息放回它该在的位置

负责人原话：「排行榜重新设计那一坨蓝太丑了」——"那一坨蓝"就是页面顶部那块品牌渐变横幅（leaderboard_page.dart:120-149，T.brandGradient，全屏最大色块）。
方案 A 的做法：整块删掉，信息不丢——榜名归页头标题、统计周期与更新时刻归页头副标题；同时把"周期"（看哪段时间）与"看哪个榜"（子榜/分部）从同一排拆成两排，周期改用 AppSegmented 分段控件；前三名徽章与头像的第二处渐变也一并删除，改为实色。
本方案不新增任何组件体系：AppSegmented / AppAvatar / AppPrice / AppEmpty / AppHairline 都是 core 里已有的。

1这一版改了什么（与现状的差异点 · 共 7 处）

  • ① 删掉渐变横幅：整块 :120-149 删除（品牌渐变 + 白字榜名 + 榜单图标）。这是负责人说的"那一坨蓝"，也是 docs/21 第一条禁止项。横幅里的两行信息不丢：榜名归页头标题，统计周期与更新时刻归页头副标题（:138-141 的「统计周期 … · 每日 03:00 更新」）。
  • ② 周期改分段控件：新增 AppSegmented(['周榜','月榜'])（core 已有组件，见 app_ui.dart:332-388），选中段实色主色 #2563EB；周期日期范围作为分段右侧的小字（10-07 至 10-13，由现有 _periodLabel() :206-216 产出）。

4为什么先给这一套（定位）

  • 最小改动：删一块 + 换两处组件 + 改三个颜色，页面结构（页头 / 控件 / 表头 / 列表 / 吸底条）不动，是"三套里最先能上线、风险最低"的一套。
  • 它解决 1–4 号缺陷，5 号缺陷（没有榜首感）只解决一半：前三名仍与其余名次同一行高，靠徽章实色 + 名次色区分。要更强的层级请选 B 或 C。
  • 适合：负责人认为"先把那一坨蓝去掉、别的不折腾"时的默认稿。
