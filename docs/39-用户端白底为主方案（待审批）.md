## 附一、脚本踩坑留痕（供后人复跑）

1. **CSSOM 取声明不能按属性名查**：`r.style.getPropertyValue('padding')` 在 Chromium 上返回空串（该 `CSSStyleDeclaration` 不支持按属性名取简写）。必须 `for (i < sd.length) sd.item(i)` 遍历。
2. **Chromium 给 `CSSStyleRule` 也挂了 `cssRules`**（CSS 嵌套 API，空 `CSSRuleList`）。递归条件写 `if (r.cssRules) walk(...)` 会把**所有样式规则**当成分组规则跳过 → 分母恒为 0。正确判据：`if (!r.selectorText && r.cssRules) walk(r.cssRules)`。
3. **模板字符串里的正则转义**：`.split(/\s+/)` 写在 `evalJs` 模板串里要写成 `String.fromCharCode(92) + 's+'`，否则 `\s` 到浏览器变成 `\s`（字面反斜杠 + s）。
4. **手机壳有 1px 边框时，`壳内元素左偏移` 要减 `borderLeftWidth`**：`r.left - pr.left` 恒为 1，`宽 = 390 / 左边距 0` 的断言会永远失败。
5. **`.stag` 的 `clip-path` 会被算成 6px 横向溢出**：改用 `overflow: hidden` + 1px 边框的 `.notch` 视觉等价。
