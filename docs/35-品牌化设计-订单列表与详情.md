**口径说明（贴验收时请连这段一起看）**

- **渐变面积 = 0**：判定为"软过渡"（`radial` / `conic` / 3+ 色阶）的元素数为 0；`HeroCard::before` 的细网格是 `repeating-linear-gradient` 的 **1px 硬边条纹**（`rgba(255,255,255,.05) 0 1px, rgba(0,0,0,0) 1px 18px`），Chromium 会把 computed value 里的 `transparent` 规范化成 `rgba(0, 0, 0, 0)`，脚本按"repeating + 含 `0px` 起点 + 含全透明停靠点"判定为**纹理**并单独计数。
- **阴影 = 0 处**：`box-shadow` 命中 3 处，全部是 `.tli.now .knob` 的 `0 0 0 3px #E8EEF7` —— 这是时间线"当前步"的**指示环**（环形、无模糊半径、无偏移、只在该步出现），**不是卡片投影**；脚本分两个桶（`card` / `ring`）分别断言，卡片桶必须为 0。
- **emoji = 0**：设计面 + 说明区统一正则 `[\u{1F300}-\u{1FAFF}\u{2B00}-\u{2BFF}\u{FE0F}\u{1F1E6}-\u{1F1FF}]`。商品名里的「➕」是**真实商品名原文**（目录里的写法，`scripts/tmp/product-inventory-audit.log:71`），码位不在 emoji 区间。
